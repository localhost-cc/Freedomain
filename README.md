## ✨ localhost.cc 是什么

**localhost.cc** 是一个**完全免费、自助、永久续费**的子域名注册与 DNS 管理平台。

只要一个主流邮箱，你就可以在我们已开放的根域名下，**一键认领**形如 `你的名字.localhost.cc` 的二级域名，并自助管理 DNS 解析。再也不用为一个 demo、一个个人作品、一个学生项目去注册付费域名。

- 🆓 **100% 免费** —— 注册免费、续费免费、DNS 解析免费
- 🚫 **零门槛** —— 无需身份证件、无需企业资料、无需付款方式
- ⚡ **秒级生效** —— 输入名称即刻拥有，无需审核
- 🌍 **Cloudflare 任播** —— 全球毫秒级解析
- 🔒 **WHOIS 隐私保护** —— 一键隐藏邮箱

## 🚀 五分钟上手

1. 打开 [https://localhost.cc](https://localhost.cc)
2. 用主流邮箱（QQ / Gmail / Outlook / 网易 / iCloud / Microsoft 等）注册
3. 选择一个根域名（例如 `localhost.cc`），输入你想要的前缀
4. 一键认领，配置 DNS 记录（A / AAAA / CNAME / TXT）
5. 几秒后全球可解析 ✨

支持 **三级 / 四级** 域名（如 `api.you.localhost.cc`、`mail.api.you.localhost.cc`）。

## 💡 为什么做这个

- 注册付费域名要钱、要实名、要付款方式 —— 这把大量学生、开发者、创作者挡在了网络身份的门外；
- 工程师应该有"做完 demo 一分钟就能展示给世界看"的体验，而不是为域名熬一个晚上；
- 小项目 / 个人作品 / 学生作业 / 独立博客 应该有一个稳定、永久免费的家。

## 🛡 安全与隐私

- 密码 **bcrypt** 单向哈希存储
- 全程 **TLS 1.2+** 加密 + Cloudflare 边缘安全
- **不收集**身份证件 / 手机号 / 地理位置 / 第三方账号密码
- **不出售** / **不交换**用户数据，不接入广告
- 内置 **WAF 路径黑名单**，扫描器流量 444 直拒
- DNS 操作走原子事务 + 上游 API 写入 + 失败补偿

详见 [隐私政策](https://localhost.cc/privacy)。
